# 思源 → 记忆锚 快速捕捉插件

在思源笔记里**选中一段文字 → 右键「发送到记忆锚」**，自动在记忆锚里生成一张复习卡片。

**单向推送**：只向记忆锚建卡，**不会修改思源里的任何内容**（不加块属性、不改块内容），没有同步与冲突。

## 前置条件

1. 记忆锚已启动：`python3 run.py`（默认 `http://127.0.0.1:7788`）
2. 记忆锚已开启 CORS（本项目已内置，内网 `Access-Control-Allow-Origin: *`）

## 安装

```bash
npm install
npm run build
```

把构建产物放到思源工作空间的插件目录：

```
工作空间/data/plugins/siyuan-plugin-mem/
├── plugin.json
└── index.js      <- dist/index.js 改名
```

重启思源或在「设置 → 集市 → 已下载」里启用插件。

## 使用

1. 在思源编辑器里选中一段文字（不选则发送光标所在整个块）
2. 右键，菜单里有两项：
   - **📌 发送到记忆锚（笔记 / 题目）** —— 用设置里的默认类型
   - **🧮 作为题目发送到记忆锚（错题）** 或 **📝 作为笔记发送到记忆锚** —— 反过来那一项，
     不用为了偶尔发一道题去改设置
3. 左下角提示 `已发送到记忆锚：卡片 #42`；发的是题目卡时额外提示
   `（题目卡，记得去补标准解答）`

卡片正文会自动清洗思源方言（清洗逻辑在记忆锚的 `app/markdown_fix.py`，任何来源粘贴都生效）：

| 思源方言 | 处理结果 |
|---|---|
| 块引/双链 `((20240301120000-abcdefg "显示文本"))` | → `显示文本` |
| IAL 属性 `{: id="..." updated="..." }` | 删除 |
| 思源标签 `#标签#` | → `#标签` |
| 嵌入块 `{{...}}` | 整行删除 |

代码块内的内容**不会被清洗**。

## 设置

插件设置里可配：

- **记忆锚地址**：默认 `http://127.0.0.1:7788`。也可以填公网实例
  （如 `https://xxxx.app.workbuddy.host`），思源是 https 页面时目标也必须是 https
- **默认标签**：逗号分隔，如 `思源, 数学`
- **默认类型**：`笔记（知识点）` 或 `题目（错题，需另填解答）`
- **追加来源回链**：开启后卡片末尾会加一行
  `> 来源：[文档名](siyuan://blocks/块ID)`，复习时点击可跳回思源原文

设置保存在插件数据目录的 `mem-capture-settings.json`，随思源工作空间走。

## 已知限制

- **图片不同步**：选中内容含图片时只发文字，并提示「仅文字已同步」
- **不查重**：同一块发两次会建两张卡，靠返回的卡号提示
- 未使用 AI 生成标题（标题由记忆锚取正文首行；后续可接 AI 标题增强）
